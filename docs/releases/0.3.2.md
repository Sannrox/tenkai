# Release notes: v0.3.2

Crate version: **`0.3.2`**. Tag: **`v0.3.2`**.

Pair with [release readiness](../release-readiness.md). Contributor credits
belong on the GitHub Release generated notes.

## Scope

Pre-1.0 patch on published GitHub release
[v0.3.1](https://github.com/Sannrox/tenkai/releases/tag/v0.3.1). Published tags
attach checksummed community hosts so operators can install without a Rust
toolchain.

Base: tag `v0.3.1` (`2f863e4`). Open release-blocking issues at crate-bump
time: **none**. Follow-ups #444 and #445 stay open.

## Compatibility and migration

| Surface | Impact for 0.3.2 |
| --- | --- |
| Crate version | `0.3.1` → `0.3.2` |
| SQLite `SCHEMA_VERSION` | Remains **11**. No migration |
| Runtime / auth / federated / model / plan / provider contracts | Unchanged |
| Optional Postgres hub | Same feature and `TENKAI_POSTGRES_URL`; hub binaries stay source-built |
| Spoke / CLI embedded | Still refuse `TENKAI_POSTGRES_URL` (ADR 0029) |
| GitHub Release assets | Community hosts for `linux-x86_64` and `darwin-aarch64` plus `SHA256SUMS` |
| Toolchain | `rust-version = "1.96.1"` |
| Defaults | Signing/approval fail closed; tenant mode / enterprise flags default off |

### Operator upgrade notes

1. **Embedded / SQLite:** install `0.3.2` community hosts from the GitHub
   Release after verifying `SHA256SUMS`, or `cargo build --release --locked`.
   No store migration. `tenkaictl --version` reports `tenkaictl 0.3.2`. See
   [release binaries](../release-binaries.md).
2. **Tenant-mode hub:** keep `--features postgres`, `TENKAI_POSTGRES_URL`,
   management credentials, and JWT trust. Hub Postgres hosts remain
   `cargo build --release --locked --features postgres --bin tenkai-server`.
3. **Spoke / community:** leave `TENKAI_POSTGRES_URL` unset. That refuse is
   unchanged.

### Rollback

Previous `0.3.1` binary plus the existing Tenkai-owned SQLite (embedded) or
Postgres (hub) store. No schema change in this patch.
