# Release notes: v0.4.1

Crate version: **`0.4.1`**. Tag: **`v0.4.1`**.

Pair with [release readiness](../release-readiness.md). Contributor credits
belong on the GitHub Release generated notes.

## Scope

Pre-1.0 patch on published GitHub release
[v0.4.0](https://github.com/Sannrox/tenkai/releases/tag/v0.4.0). Operators get
the hub `tenkai-server-postgres` GitHub asset, `--ui-dir` symlink refuse, and
bind-before-legacy-import so `/healthz` answers while a large store opens.

Base: tag `v0.4.0` (`36c20ff`). Open release-blocking issues at crate-bump
time: **none**. Follow-up #511 stays open.

### Operator upgrade notes

1. **Embedded / SQLite:** install `0.4.1` community hosts from the GitHub
   Release after verifying `SHA256SUMS` and the attestation, or
   `cargo build --release --locked`. No store migration. `tenkaictl --version`
   reports `tenkaictl 0.4.1`. See [release binaries](../release-binaries.md).
2. **`tenkai-server` community host:** still built with `--features ui` and
   serves the pinned console at `/ui/`. `--ui-dir` refuses symlinks that leave
   the console root. See
   [run tenkai-server](../run-tenkai-server.md#open-the-web-console).
3. **Tenant-mode hub:** this is the first published tag that attaches
   `tenkai-server-postgres-<platform>` (`--features postgres,ui`). Verify
   checksum and attestation the same way as community hosts. Keep
   `TENKAI_POSTGRES_URL`, management credentials, JWT or OIDC trust, and
   `--tenant-mode`. Non-loopback Postgres URLs still require verified TLS.
   Source build remains valid:
   `cargo build --release --locked --features postgres --bin tenkai-server`.
4. **Spoke / community:** leave `TENKAI_POSTGRES_URL` unset. That refuse is
   unchanged.
5. **Large legacy stores:** `tenkai-server` binds first and answers `/healthz`
   while import runs. `/readyz` returns 503 until the store is open. Graph
   import commits in batches and resumes after a restart.

### Rollback

Previous `0.4.0` binary plus the existing Tenkai-owned SQLite (embedded) or
Postgres (hub) store. No schema change in this patch. Recovery never depends
on sekai-chisei.

## User-visible changes

### Added

- GitHub Release attaches hub `tenkai-server-postgres-<platform>` built with
  `--features postgres,ui` for `linux-x86_64` and `darwin-aarch64`, next to
  the five community `--features ui` hosts (#514)

### Fixed

- `tenkai-server` binds the listener and serves `/healthz` before legacy
  graph import; `/readyz` returns 503 until the store is open (#516)
- Legacy graph import commits in batches and resumes after a readiness
  restart (#516)

### Security

- `--ui-dir` `/ui` file map refuses symlinks that would leave the console
  root (#515)

### Migration

- None. `SCHEMA_VERSION` remains 12. HTTP contract id stays `tenkai.http.v1`.

## Out of scope for 0.4.1

- Advertising product `high_availability` capability
- Catalog service extraction
- Identity-plane DB co-location
- Extra platforms or crates.io
- Rewriting `docs/releases/0.4.0.md`
- #511 (export operation-bound feedback observations)
