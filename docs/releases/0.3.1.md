# Release notes: v0.3.1

Crate version: **`0.3.1`**. Tag: **`v0.3.1`**.

Pair with [release readiness](../release-readiness.md). Contributor credits
belong on the GitHub Release generated notes.

## Scope

Pre-1.0 patch on published GitHub release
[v0.3.0](https://github.com/Sannrox/tenkai/releases/tag/v0.3.0). Tenant-mode
hubs with PostgreSQL start instead of panicking or refusing
`TENKAI_POSTGRES_URL` while opening control-plane SQLite.

Base: tag `v0.3.0` (`8ba1c35`). Open release-blocking issues at crate-bump
time: **none**.

## Compatibility and migration

| Surface | Impact for 0.3.1 |
| --- | --- |
| Crate version | `0.3.0` → `0.3.1` |
| SQLite `SCHEMA_VERSION` | Remains **11**. No migration |
| Runtime / auth / federated / model / plan / provider contracts | Unchanged |
| Optional Postgres hub | Same feature and `TENKAI_POSTGRES_URL`; tenant-mode now starts |
| Spoke / CLI embedded | Still refuse `TENKAI_POSTGRES_URL` (ADR 0029) |
| Toolchain | `rust-version = "1.96.1"` |
| Defaults | Signing/approval fail closed; tenant mode / enterprise flags default off |

### Operator upgrade notes

1. **Embedded / SQLite:** replace `0.3.0` binaries with `0.3.1`. No store
   migration. `tenkaictl --version` reports `tenkaictl 0.3.1`.
2. **Tenant-mode hub:** keep `--features postgres`, `TENKAI_POSTGRES_URL`,
   management credentials, and JWT trust. Control-plane state stays SQLite;
   Postgres remains the tenant store. `0.3.0` either panicked inside
   `postgres::Client::connect` on a Tokio worker or refused the URL while
   opening embedded application state.
3. **Spoke / community:** do not set `TENKAI_POSTGRES_URL`. That refuse is
   unchanged.

### Rollback

Previous `0.3.0` binary plus the existing Tenkai-owned SQLite (embedded) or
Postgres (hub) store. No schema change in this patch.

## User-visible changes

### Fixed

- Sync `postgres::Client` connect, queries, and Drop run on a thread with no
  Tokio handle, so tenant-mode startup no longer panics with "Cannot start a
  runtime from within a runtime" (#438, #439)
- Tenant-mode hub opens control-plane SQLite without refusing
  `TENKAI_POSTGRES_URL`; spoke/CLI `open_embedded` still fails closed
  (#440, #441)

## Out of scope for 0.3.1

- Advertising product `high_availability` capability
- Catalog service extraction
- Identity-plane DB co-location
